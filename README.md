# Binance Spot Telegram Trading Bot for Railway

Telegram-бот для анализа spot-рынка Binance: стакан ордеров, уровни поддержки/сопротивления, Fibonacci по выбранному таймфрейму, наклонная трендовая линия, прогноз движения, вероятность LONG/SHORT, PNG-график и мониторинг изменений стакана.

> Важно: бот не совершает сделки и не является финансовой рекомендацией. Это аналитический инструмент.

## Что доработано в текущей версии

- Крупный четкий график 1920x1080, темная тема, увеличенные шрифты и подписи уровней.
- Fibonacci строится по свечам выбранного таймфрейма: `15m`, `1h`, `4h`, `1d`, `1w`.
- На графике подписываются все уровни Fib: `0%`, `23.6%`, `38.2%`, `50%`, `61.8%`, `78.6%`, `100%`.
- Поддержка и сопротивление строятся по кластерам ликвидности spot-стакана Binance.
- Добавлена наклонная линия:
  - при восходящем сценарии — наклонная поддержка по повышающимся минимумам;
  - при нисходящем сценарии — наклонное сопротивление по понижающимся максимумам.
- На графике показаны проценты `LONG` и `SHORT`.
- Добавлен прогноз возможного движения: стрелки на графике, цель 1, цель 2, процент движения до целей и уровень отмены сценария.
- В текст анализа добавлены наклонка и прогноз движения по уровням.
- Автосигнал мониторинга стакана также отправляет обновленный график.

## Возможности

- Анализ монеты по сообщению: `btc`, `eth`, `sol`.
- `/help` — список команд.
- `stakan on` / `stakan off` — включить/выключить мониторинг стакана.
- `new btc` / `new eth` — добавить монету в мониторинг.
- `del btc` / `del eth` — удалить монету из мониторинга.
- `list` — показать монеты в памяти.
- Автосигнал каждые 30 минут при сильном изменении стакана.

## Кнопки в боте

Главное меню:

- `📚 Стакан ордеров` — включает/выключает мониторинг стакана.
- `⚙️ Настройки` — выбор таймфрейма.
- `🖼 Визуализация` — формат отправки анализа.
- `🏓 Пинг` — отклик, память, uptime, версия.

Настройки таймфрейма:

- `15m`
- `1h`
- `4h`
- `1d`
- `1w`
- `⬅️ Назад`

Визуализация:

- `Одно сообщение: картинка + анализ`
- `Два сообщения: график сверху + текст`
- `⬅️ Назад`

## Railway deploy

1. Создайте бота через `@BotFather` и получите токен.
2. Загрузите проект в GitHub.
3. В Railway создайте новый Project → Deploy from GitHub.
4. В Variables добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен Telegram-бота.
   - остальные переменные можно взять из `.env.example` или оставить по умолчанию.
5. Railway запустит worker командой `python main.py`.

## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# заполните TELEGRAM_BOT_TOKEN
python main.py
```

## Настройки через env

- `TELEGRAM_BOT_TOKEN` — обязательно.
- `BINANCE_BASE_URL` — по умолчанию `https://api.binance.com`.
- `DEFAULT_QUOTE` — по умолчанию `USDT`.
- `ORDERBOOK_LIMIT` — по умолчанию `1000`.
- `MONITOR_INTERVAL_MINUTES` — по умолчанию `30`.
- `STRONG_CHANGE_THRESHOLD` — процент изменения силы стакана для сигнала, по умолчанию `35`.
- `BOT_VERSION` — версия, по умолчанию `00001`.

## Файлы

- `main.py` — точка запуска.
- `bot/telegram_bot.py` — команды и кнопки Telegram.
- `bot/binance_client.py` — публичные spot API Binance.
- `bot/analysis.py` — уровни, Fibonacci, наклонка, прогноз, проценты long/short.
- `bot/charting.py` — крупный PNG-график 1920x1080.
- `bot/storage.py` — SQLite память пользователей/монет.
- `bot/monitor.py` — фоновый мониторинг стакана.
- `Procfile`, `railway.json` — адаптация под Railway.
